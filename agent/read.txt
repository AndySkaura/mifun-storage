Telegram File System (TGFS) Agent Development Specification
1. 项目概述

实现一个基于 Telegram Bot 的轻量文件系统。

目标：

使用 MySQL 保存文件元数据
使用 Telegram Channel 作为文件存储
Node.js + TypeScript 提供 API
不包含：
用户系统
权限系统
分享
上传任务
文件去重

核心模型：

              HTTP API
                  |
                  |
              File Service
                  |
        +---------+----------+
        |                    |
      MySQL              Telegram
        |                    |
    files表          telegram_files表
                             |
                         TG Channel

3. 数据库设计
files

文件系统表。

CREATE TABLE files
(
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,


    parent_id BIGINT UNSIGNED NULL,


    name VARCHAR(255) NOT NULL,


    type ENUM(
        'file',
        'folder'
    ) NOT NULL,


    size BIGINT DEFAULT 0,


    mime_type VARCHAR(100),


    extension VARCHAR(20),


    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,


    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP 
        ON UPDATE CURRENT_TIMESTAMP,


    INDEX idx_parent_id(parent_id)

);
telegram_files

Telegram存储映射。

CREATE TABLE telegram_files
(
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,


    file_id BIGINT UNSIGNED NOT NULL,


    telegram_chat_id BIGINT NOT NULL,


    telegram_message_id BIGINT NOT NULL,


    telegram_file_id VARCHAR(255) NOT NULL,


    telegram_file_unique_id VARCHAR(255),


    file_size BIGINT,


    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,


    INDEX idx_file_id(file_id),

    UNIQUE KEY uk_message(
        telegram_chat_id,
        telegram_message_id
    )

);
4. Prisma Schema

schema.prisma

model File {

  id BigInt @id @default(autoincrement())


  parentId BigInt?


  name String


  type String


  size BigInt @default(0)


  mimeType String?


  extension String?


  createdAt DateTime @default(now())


  updatedAt DateTime @updatedAt


  telegram TelegramFile?


  @@index([parentId])

}


model TelegramFile {

  id BigInt @id @default(autoincrement())


  fileId BigInt @unique


  telegramChatId BigInt


  telegramMessageId BigInt


  telegramFileId String


  telegramFileUniqueId String?


  fileSize BigInt?


  createdAt DateTime @default(now())


  file File @relation(
    fields:[fileId],
    references:[id],
    onDelete:Cascade
  )

}

8. 上传代码逻辑示例
async function uploadFile(
    file: MultipartFile,
    parentId:number
){

    // 1. 上传TG

    const tgResult =
        await telegram.upload(file)


    // 2. 创建文件

    const dbFile =
        await prisma.file.create({

        data:{
            name:file.filename,
            parentId,
            type:"file",
            size:file.size
        }

    })


    // 3. 保存TG映射

    await prisma.telegramFile.create({

        data:{
            fileId:dbFile.id,

            telegramChatId:
              tgResult.chatId,

            telegramMessageId:
              tgResult.messageId,

            telegramFileId:
              tgResult.fileId
        }

    })


}

14. 开发约束

必须：

使用 TypeScript
使用 async/await
文件下载必须 Stream
不落地临时文件
Telegram作为唯一存储

禁止：

❌ 保存文件到本地
❌ Base64存储
❌ 文件二进制写MySQL
❌ 引入用户权限系统

这个设计基本就是一个最小版 Telegram Object Storage + Virtual File System
